# Getting Started

ShapeIC CellKit is designed to run within the
[IIC-OSIC-TOOLS](https://github.com/iic-jku/IIC-OSIC-TOOLS)
Docker environment, which provides the required EDA tools and
Process Design Kits (PDKs).

This section guides you through setting up the environment,
installing CellKit, and generating your first analog layout.

## Requirements

Before getting started, make sure you have:

- **Docker or Podman**
- **Git**
- **IIC-OSIC-TOOLS**

Python 3.12 is required by CellKit and will be configured
within the container.

:::{note}
All installation and execution steps in this documentation
are performed **inside the IIC-OSIC-TOOLS container**, unless
explicitly stated otherwise.
:::
